# PM2.5 Air Quality Forecasting Using Hybrid ML Models

Welcome to the official GitHub repository for PM2.5 forecasting using hybrid machine learning models such as Grey Wolf Optimizer (GWO) + LSTM and XGBoost.

## Files

- `Hybrid_GWO+LSTM.ipynb`: Main notebook containing data preprocessing, model training, and results.

## Features

- Forecasts PM2.5 levels using historical pollutant data
- Uses both traditional (XGBoost) and hybrid models (GWO + LSTM)
- Evaluation metrics and visual comparison of predictions

## Tech Stack

- Python, Pandas, NumPy
- Scikit-learn, TensorFlow/Keras
- Jupyter Notebook
- mealpy for GWO optimization
